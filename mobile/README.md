# 截译 · Android 体验版

把截图里的文字取出来，轻点选中需要的词句，再翻译、提问、复制或分享。适合英文 App 提示、报错截图、外语社区和无法复制的内容。

支持 **Android 8.0 及以上**。当前版本为 `0.1.0-alpha.1`，可从 [GitHub Android alpha Release](https://github.com/caoy2099-sketch/ScreenLingo/releases/tag/mobile-v0.1.0-alpha.1) 下载；这是 debug 签名个人体验包，尚未完成不同品牌手机的真机兼容性验收。

## 怎么用

1. 像平时一样截屏，在相册中点“分享 → 截译”；也可以打开截译，点“导入截图”或“粘贴文字”。
2. 识别完成后，用“按词”或“按句”点选需要的部分。识别不准时，点“编辑”修改原文。
3. 点“翻译成中文”，或使用复制、分享、查找。“问一问这段内容”可以进一步解释报错或术语，需要先配置自己的模型。

支持文字选择菜单的 App 中，选中文字后也可能在菜单里找到“截译”。入口是否出现由系统和原 App 决定；找不到时可以使用分享或粘贴。

翻译和回答显示在工作台，长按结果即可选择、复制。点“清除本次内容”可清空当前图片、文字和结果。

## 翻译与提问

默认使用**必应在线翻译**，无需账号或 API Key。只有选中的文字会发给必应，截图不会随翻译上传。

想使用自己的模型时，在“设置”中填写兼容 OpenAI 格式的服务地址、API Key 和文字模型名称并保存。此后翻译和文字提问都使用该模型；清空文字模型名称并保存，可恢复必应翻译。模型服务可能收费，具体由服务商决定。

截图提问还需填写支持图片输入的“看图模型名称”。在“问一问”里主动勾选“附上当前截图”，才会将**整张导入的图片**连同问题、所选文字发给该模型。发送前请检查截图里是否有不想分享的内容。

## 离线、网络与隐私

- 中英文识字在手机本地运行，模型随应用提供；离线也能导入、选词和复制。在线翻译与远程模型提问需要网络。
- 识字使用 Google ML Kit。根据其[隐私说明](https://developers.google.com/ml-kit/terms)，SDK 会发送性能与使用指标，可能联系服务器检查更新和兼容性；识别的图片、文字与结果在设备处理，不因识字发送给 Google。这不等同于“应用完全不产生网络通信”。
- 未开启代理时使用手机当前网络；开启系统代理或 VPN 时，遵循系统设置和 VPN 的分流规则。电脑上的 v2rayN 不会自动为手机提供代理。
- 只读取你主动选择或分享的图片，粘贴时才读取剪贴板。不需要无障碍、悬浮窗或持续录屏权限。
- 密钥加密保存在手机本机，图片、原文与结果不保存为历史记录。复制后的内容由系统剪贴板管理；分享和查找会把所选文字交给对应应用或搜索服务。
- 服务地址须使用 HTTPS。`localhost` / `127.0.0.1` 指手机本身，不是电脑；不能直接照搬电脑上本地模型的地址。

## 体验版的限制

- 当前只支持 Android。没有 iPhone 版本，也没有跨 App 悬浮球、一键自动截屏或后台取词。
- 中文分词、断句和图片识别可能出错；请核对报错编号、命令和路径。点选支持多个片段，暂不支持拖拽选词。
- 超过视觉模型 2 MB 图片上限的截图仍可完成本地识字、选择和文字翻译，但不能附图提问；请裁剪后重新导入才能启用附图。
- 每次最多处理 10,000 个字符和 600 个文字片段，问题最多 2,000 个字符。长截图建议先裁出所需部分。
- 必应网页接口可能因验证、限额或页面变化而暂时失效；可以稍后重试或配置自己的模型。模型回答也需要核实。
- 本版不保存会话历史；被系统结束后，当前内容可能丢失。重要结果请先复制或分享。
- 分享入口、图片授权、深色模式、大字体，以及直连、系统代理和 VPN 的组合仍需在不同手机上验证。
