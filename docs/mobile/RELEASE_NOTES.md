# 截译 Android `0.1.0-alpha.1`

这是 ScreenLingo 的首个 Android 体验版，面向个人试用和早期反馈。

## 可以做什么

- 从相册导入截图，或从其他应用分享图片、文字到截译。
- 使用 Photo Picker 和系统文字选择菜单作为入口；也支持主动粘贴。
- 在手机本地识别中文和英文，按词或按句点选需要的片段。
- 将选中文字发送给必应在线翻译，或发送给用户配置的 OpenAI 兼容文字模型。
- 复制、分享、查找选中文字；使用配置的视觉模型进行可选截图提问，也可以只附当前截图提问。
- 使用 Android Keystore 加密保存模型 API Key，不保存内容历史。

## 使用前请知道

- 支持 Android 8.0/API 26 及以上。
- 这是 debug 签名体验包，不是应用商店正式包；首次安装或覆盖安装可能需要先卸载旧包。
- 未连接到电脑的 v2rayN；移动端只遵循手机自己的网络、VPN 和代理设置。
- 图片识字在本地完成，但 ML Kit 仍可能发送性能和使用指标；详情见 [移动版说明](../../mobile/README.md)。
- 截图只在提问时主动勾选“附上当前截图”后发送整张导入图片。
- 如果图片无法压缩到视觉模型的 2 MB 附件上限，仍可识字、选择和文字翻译；界面会禁用附图选项，并提示裁剪后重新导入。
- 必应网页接口、用户配置的模型服务和系统分享接收方各自适用其服务条款。
- 当前没有 Android 真机矩阵验收，复杂长图、不同厂商系统、无 GMS 环境和代理组合仍需反馈。
