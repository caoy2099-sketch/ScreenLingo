# 截译 ScreenLingo v0.2.0

这一版把 ScreenLingo 从主窗口应用推进成贴进 Windows 操作流的轻量插件：截图译文直接覆盖原选区，选中文本的译文在光标旁以小窗出现，桌面和文件夹右键、系统托盘都能直接开始。程序免费开源，采用 MIT 许可证。

## 下载

- `ScreenLingo-0.2.0-win-x64.zip`（推荐）：完整解压后进入 `win-unpacked` 文件夹，运行其中的 `截译 ScreenLingo.exe`。日常启动更快，请不要单独移动 EXE 文件。
- `ScreenLingo-0.2.0-x64.exe`（便携版）：直接运行，适合临时携带；每次启动会先解压，速度较慢。
- `SHA256SUMS.txt`：下载后可用来核对文件完整性。

两个版本都包含英文 OCR 模型，Windows 10/11 x64 无需安装 Node.js。请只从本项目的 GitHub Releases 页面下载。

## 这一版新增

- **截图翻译原位覆盖**：`Alt+Shift+S` 框选后，译文浮层直接覆盖截图区域，不再把工作台叫到前台。浮层可复制译文、打开工作台，关闭后晚到的结果不会重新弹出。
- **选中文本小窗**：新增 `Alt+Shift+X`，通过 Windows UI Automation 读取当前选区，在光标旁显示轻量结果窗。不会模拟 `Ctrl+C`，不会改写剪贴板；读不到时会提供“翻译剪贴板”退路。
- **Windows 右键入口**：桌面和文件夹空白处右键可选择“截译 · 截屏翻译”或“截译 · 翻译剪贴板”。Windows 11 中位于“显示更多选项”。这些菜单项只写入当前用户 `HKCU`，可在设置中随时关闭和移除。
- **托盘入口**：托盘右键提供截屏翻译、翻译选中文本、翻译剪贴板三个动作。
- **第二实例快速启动**：从右键菜单启动时通过 `--quick-action` 直接进入浮层；程序已运行时由现有进程接管，不打开主窗口。
- **设置与隐私说明**：新增选中文本热键、Windows 右键菜单开关和 [Windows 集成说明](https://github.com/caoy2099-sketch/ScreenLingo/blob/main/docs/WINDOWS_INTEGRATION.md)。

## 使用

1. 启动程序；默认会自动添加当前用户的桌面/文件夹右键菜单，也可在“设置 → 快捷键与行为”中关闭。
2. 在任意窗口按 `Alt+Shift+S`，框选英文报错，等待浮层覆盖显示译文。
3. 选中文字后按 `Alt+Shift+X`，或复制文字后按 `Alt+Shift+T`，在光标旁查看小窗结果。
4. 右键桌面/文件夹空白处，或右键托盘图标，也可以直接开始。
5. 配置支持图片的视觉模型后，可在完整工作台中继续使用“截图提问”。只有主动提问时，截图才会发送到你配置的模型服务。

## 升级说明

- 从 0.1.0 替换为 0.2.0 文件时会保留原有设置和 API Key。
- 已有的会话、历史和内存中的截图不会迁移；本程序默认不保存截图历史。
- 若你曾关闭桌面右键菜单，升级后的首次启动会按当前设置重新同步；新的安装默认启用该菜单。

## 已知限制

- 随包 OCR 模型目前主要识别英文代码报错；也可以直接粘贴其他语言文字进行翻译。
- 选中文本读取依赖目标应用向 Windows UI Automation 暴露选区。现代 Chromium/Electron 编辑器和多数原生文本框通常支持；部分自绘控件、旧式控件或管理员权限窗口可能不支持。
- Windows 没有公开接口能让普通应用把自己的项目插入所有软件的原生右键菜单；截译不做进程注入，所以“翻译选中文本”使用快捷键或托盘入口，资源管理器菜单只覆盖桌面和文件夹空白处。
- OCR 对过小、模糊或强压缩的文字可能不准确，缩小框选范围通常会改善结果。
- 这是未签名的公开测试版，首次启动时 Windows SmartScreen 可能显示“未知发布者”。请确认文件来自本项目 Releases 页面后再选择运行。
- 当前没有自动更新功能，后续版本需要从 Releases 页面手动下载。
