# 截译 ScreenLingo v0.1.0

这是首个公开测试版，适合个人试用。程序免费开源，采用 MIT 许可证。

## 下载

- `ScreenLingo-0.1.0-win-x64.zip`（推荐）：完整解压后进入 `win-unpacked` 文件夹，运行其中的 `截译 ScreenLingo.exe`。日常启动更快，请不要单独移动 EXE 文件。
- `ScreenLingo-0.1.0-x64.exe`（便携版）：直接运行，适合临时携带；每次启动会先解压，速度较慢。
- `SHA256SUMS.txt`：下载后可用来核对文件完整性。

两个版本都包含英文 OCR 模型，Windows 10/11 x64 无需安装 Node.js。请只从本项目的 GitHub Releases 页面下载。

## 使用

1. 启动程序后，在任意终端、编辑器或日志窗口按 `Alt+Shift+S`，框选英文报错。
2. 程序在本机完成英文 OCR，再将文字翻译成中文。
3. 也可以先复制文字，再按 `Alt+Shift+T` 翻译剪贴板内容。
4. 配置支持图片的视觉模型后，可在当前截图上使用“截图提问”。只有主动提问时，截图才会发送到你配置的模型服务。

## 网络与服务

- 默认翻译使用必应网页接口，也可切换 Google 或 OpenAI 兼容服务。
- “自动”网络模式会兼容 v2rayN 已开启和未开启的情况；也可以在设置中手动选择系统代理、直连或本机代理。
- 使用远程模型时，远程端点必须是 HTTPS；本机 Ollama 等回环地址允许使用 HTTP。
- 翻译服务需要联网。完全离线翻译需要另行安装本地模型并配置 OpenAI 兼容接口。

## 已知限制

- 随包 OCR 模型目前主要识别英文代码报错；也可以直接粘贴其他语言文字进行翻译。
- OCR 对过小、模糊或强压缩的文字可能不准确，缩小框选范围通常会改善结果。
- 这是未签名的公开测试版，首次启动时 Windows SmartScreen 可能显示“未知发布者”。请确认文件来自本项目 Releases 页面后再选择运行。
- 当前没有自动更新功能，后续版本需要从 Releases 页面手动下载。
