# 截译 Android 0.1.0-alpha.2

这次更新将 Android 启动图标换成与桌面版一致的冰青色「译」字，提升小尺寸辨识度。移动端继续使用现有浅色／深色界面，Windows 玻璃主题没有移植到此 APK。

## 下载与安装

- `ScreenLingo-mobile-0.1.0-alpha.2-debug.apk`：Android 8.0 及以上个人体验包。
- `SHA256SUMS.txt`：用于核对 APK 的 SHA-256。

版本号为 `0.1.0-alpha.2`，版本代码为 `2`。这是 debug 签名体验版，不是应用商店正式发行包。

APK 约 63.5 MB，包含中英文识字模型。已核对与上一版 alpha.1 构建使用相同签名，可作为覆盖升级包；安装前请先复制需要保留的当前内容，实际设备升级仍待验证。

## 使用

1. 从相册分享截图到「截译」，或在应用中选择「导入截图」「粘贴文字」。
2. 本地识字完成后，按词或按句选择需要的内容。
3. 翻译成中文、复制、分享或继续提问；附图提问需要配置视觉模型并主动勾选当前截图。

中英文识字模型随包提供；在线翻译和远程模型提问需要网络。系统 VPN／代理由 Android 网络栈处理。
