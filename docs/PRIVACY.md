# 隐私说明

ScreenLingo 是本地运行的个人辅助翻译工具，不包含账号系统、遥测、广告或自动更新服务。

## 各功能的数据流

| 操作 | 本机处理 | 可能发送到网络 |
| --- | --- | --- |
| 框选截图 / 打开图片 | 截图、图片校验、英文 OCR | 默认只发送 OCR 文字给所选翻译服务 |
| 翻译剪贴板 | 用户主动读取的本次剪贴板文字 | 文字发送给所选翻译服务 |
| 手动翻译文本 | 文本编辑与展示 | 文字发送给所选翻译服务 |
| 截图提问 | 图片校验、OCR 上下文 | 图片、问题及可能的 OCR 文本发送给用户配置的视觉模型端点 |

默认必应及可选 Google 模式不会上传截图。OpenAI 兼容模式的数据接收方由用户填写的端点决定，请只配置自己信任的服务。

## 本地保存

- 普通设置保存在 Electron 的应用数据目录。
- API Key 仅在 Windows 安全存储可用时加密保存；不可用时保存会失败。
- 截图、OCR 原文、译文和问答内容默认不写入历史数据库，退出程序后不会由 ScreenLingo 保留。
- 必应翻译所需的网页会话 Cookie 保存在隔离的内存网络会话，不读取浏览器的登录状态。

## 网络限制

- 非本机端点必须使用 HTTPS。
- 本机 Ollama 可使用 `http://127.0.0.1`、`http://localhost` 或 `http://[::1]`。
- 请求不跟随 HTTP 重定向，避免文本、图片或密钥被转发到另一个地址。
- 响应有体积上限，超时或用户取消时会中止请求。
- 自动模式检测系统代理与本机 v2rayN 常用端口；代理不存在时直连。选择了可用代理但其远端请求失败时，不自动绕过代理重发。
- 手动代理仅接受本机 HTTP / SOCKS5 地址。本机模型始终直连，不经过外部代理。
- 不读取 v2rayN 的节点、订阅、账号或密钥，不修改系统代理。
- 必应网页初始化可能分别访问 `cn.bing.com` 和 `www.bing.com` 的固定地址；取得有效会话前不发送用户文字。

## 用户控制

用户可以随时按停止按钮取消当前 OCR、翻译或截图提问。关闭“最小化到托盘”后，关闭主窗口会直接退出程序；从托盘选择“退出”也会结束后台进程。
